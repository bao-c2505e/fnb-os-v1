## Brand Snapshot

- **Brand name:** Vị Cuốn
- **Category:** Vietnamese F&B / casual dining / fresh rolls and street-food-inspired meals
- **Market:** Vinh, Nghệ An, Vietnam
- **Positioning:** Vietnamese street food with a more polished, trustworthy, warm brand experience
- **Default price range:** Around 60,000–80,000 VND per person (Owner may update)
- **Main menu examples:**
  - Bánh Tráng Cuốn Thịt Heo
  - Bún Trộn Mắm Nêm
  - Gỏi Cuốn
  - Heo Quay Nướng Lu
- **Brand personality:**
  - Friendly
  - Warm
  - Trustworthy
  - Approachable
  - Clean and appetizing

---

## Target Customers

| Segment | Description |
|---------|-------------|
| Office workers | Lunch/dinner near workplace, time-sensitive, value-conscious |
| Young people / students | Affordable, tasty, shareable on social media |
| Families | Group dining, variety, kid-friendly options |
| Local diners in Vinh | Residents seeking familiar, reliable Vietnamese street food |
| Delivery customers | Convenience-focused, order via apps |
| Groups | Friends looking for light but satisfying shared meals |

---

## Core Selling Points

1. Fresh, easy-to-eat Vietnamese food — daily made, not frozen
2. Suitable for lunch, dinner, group meals, and delivery
3. Friendly local brand with a warm, approachable vibe
4. Clean, appetizing presentation — suitable for food content
5. Accessible price point for repeat purchase (60k–80k VND/person)
6. Strong local identity in Vinh, Nghệ An

---

## Tone of Voice

| Principle | Guideline |
|-----------|-----------|
| Language | Vietnamese first; use local dialect warmth where appropriate |
| Style | Friendly, clear, warm — conversational, not corporate |
| Price level signal | Not luxury, not cheap — approachable and honest |
| Claims | Avoid overclaiming (e.g., "best in Vietnam"); use honest, grounded language |
| CTAs | Simple, direct: "Đặt ngay", "Xem menu", "Ghé thử hôm nay" |
| Emojis | Light use — one or two per post; never spammy |

---

## Content Pillars

| Pillar | Description |
|--------|-------------|
| Menu spotlight | Feature dishes with appetite-first visual and copy |
| Behind the scenes / kitchen freshness | Show prep, ingredients, cooking — build trust |
| Customer moments | Real-feeling scenarios (no fake reviews); group, family, lunch |
| Lunch / dinner suggestions | Timely content aligned with meal periods |
| Combo / offer | Highlight value bundles (only when Owner provides real offer) |
| Local lifestyle in Vinh | Tie into Vinh daily life, weather, local occasions |
| Brand trust and cleanliness | Hygiene, freshness, care — reassurance content |
| Seasonal / event content | Tết, local holidays, rainy season, back-to-school, etc. |

---

## Offer Rules

- **Do not invent discounts** unless Owner provides them.
- If an offer is missing, use placeholder: `[OWNER_TO_PROVIDE_OFFER]`
- Do not invent fake customer reviews or testimonials.
- All offers must be reviewed by Owner before appearing in published content.

---

## Compliance / Safety

| Rule | Detail |
|------|--------|
| No misleading claims | Do not overstate freshness, sourcing, or health benefits without Owner confirmation |
| No fake scarcity | Do not write "only X left" or "limited offer" unless Owner confirms |
| No fake reviews | Never fabricate customer quotes or star ratings |
| No auto-publishing | All content requires Owner approval before any public post |
| Approval gate | Any public-facing output (caption, ad, reply) must be marked Approved by Owner |

## Replaceable Brand Context

This file (`brand-brain/vi-cuon.md`) is the **default Brand Brain** for FnB OS V1.

Other F&B brands can replace this file to use the same agents and schemas without any structural changes:

1. Copy this file and rename it (e.g., `brand-brain/your-brand.md`).
2. Replace all Vị Cuốn-specific values (brand name, menu, market, positioning, tone, content pillars).
3. Update `brand_id` and `brand_name` in all schema inputs to match the new brand.
4. The agents, schemas, and workflow structure remain unchanged.

The **core agent logic, approval gates, and safety rules are brand-neutral** — only the Brand Brain content changes.
