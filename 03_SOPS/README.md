# 03_SOPS — Standard Operating Procedures

Every automated workflow in FnB OS V1 is governed by a SOP document.
SOPs define the trigger, steps, decision points, outputs, and failure handling.

## SOP Format Rules
Every SOP must contain:
1. Trigger — what starts this process
2. Pre-conditions — what must be true before running
3. Steps — numbered, specific, agent-assigned
4. Decision Points — yes/no branches
5. Output — what is produced
6. Failure Handling — what happens if a step fails
7. Approval Gate — who approves before action
8. Logging — what is logged and where
