# 01_BRAIN — Brand Intelligence Layer

This folder contains the foundational knowledge documents for Vị Cuốn.
All agent prompts and workflows reference these files as their knowledge base.

## Files

| File | Purpose |
|------|---------|
| `brand_brain.md` | Brand identity, tone, values, visual guidelines |
| `menu_brain.md` | Full menu, pricing, ingredients, combos, seasonal items |
| `customer_brain.md` | Customer personas, segments, FAQs, pain points |
| `offer_brain.md` | Promotions, combos, discount logic, upsell rules |
| `content_brain.md` | Content pillars, posting strategy, caption rules |
| `ads_brain.md` | Ads targeting, creatives strategy, budget logic |
| `crm_brain.md` | CRM segmentation, follow-up rules, loyalty triggers |
| `comment_reply_brain.md` | Reply tone, escalation rules, FAQ answers |
| `design_brain.md` | Visual style, colors, fonts, layout rules for creatives |

## Update Rules
- Any change to BRAIN files must be logged in `06_HANDOFF/DECISION_LOG.md`
- BRAIN files are versioned — add `## Changelog` section at bottom of each file
- Agents must reference BRAIN files at the start of every session
- BRAIN files are written in plain markdown — no code, no JSON
