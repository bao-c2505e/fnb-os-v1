## Customer Journey

```
Discover (Social Media / Word of Mouth)
  → Interested (Saves post / Follows page)
  → First Order (Combo Trưa or introductory item)
  → Repeat (Loyalty trigger after 2nd order)
  → Advocate (Shares content, leaves review)
```

## CRM Lifecycle Stages

| Stage | Definition | Trigger |
|-------|-----------|---------|
| New | First-time inquiry or first order | Zalo / DM / Phone |
| Active | Ordered within last 30 days | Order system |
| At-Risk | No order in 30–60 days | Time-based |
| Lapsed | No order in 60+ days | Time-based |
| VIP | 5+ orders or high spend | Order history |

## Escalation Rules
- Complaints about food safety → immediate human response, do NOT use auto-reply
- Negative reviews (1–2 stars) → flag for manager review
- Refund requests → route to human staff
- Sensitive topics (food poisoning, allergy reactions) → escalate immediately
